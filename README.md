# 🛡️ ScamShield
### Don't Trust. Verify. Stay Protected.

**ScamShield** is a privacy-first, hybrid cybersecurity threat detection web application designed to help users identify suspicious messages, potentially malicious URLs, phishing attempts, and online scams.

It focuses on explainable security analysis — showing users what triggered a warning, why it matters, and what action they should consider.

🌐 **Live Demo:** https://incomparable-faun-95a0ba.netlify.app

📂 **GitHub Repository:** https://github.com/Ananta1229/promtwars-project

---

## ✨ Key Features

- **Message Scanner:** Analyses suspicious SMS, WhatsApp forwards, emails, and other text for potential scam indicators.
- **URL Inspector:** Examines URL structures and suspicious domain patterns.
- **Evidence-Based Detection:** Highlights suspicious phrases and explains detected warning indicators.
- **Risk Assessment:** Provides risk levels and actionable security recommendations.
- **Security Awareness:** Includes an awareness section to help users understand online threats.
- **Privacy Center:** Communicates the application's privacy approach and data-handling practices.
- **On-Device Analysis:** Core detection is designed to run locally in the browser.

## 🚀 Run Locally

### Prerequisites
- Node.js
- npm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Ananta1229/promtwars-project.git

# Enter the project directory
cd promtwars-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

### Quality Checks

```bash
npm run lint
npm run typecheck
```

## 🔐 Privacy & Security Philosophy

ScamShield is designed around privacy-first principles:

- Local-first threat analysis.
- No automatic opening of submitted URLs.
- Evidence-based warnings instead of unsupported safety guarantees.
- Clear distinction between suspicious, inconclusive, and lower-risk results.
- Privacy-conscious handling of user-submitted information.

Security assessments are heuristic indicators and should not be treated as guarantees that a message, URL, or website is safe.
